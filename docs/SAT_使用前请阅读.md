# BACoffee SAT 使用前请阅读

BACoffee SAT（Student Add Tool）是 BACoffee 的附属学生头像导入工具，用于把用户准备的头像图片检查、裁剪并导入 BACoffee 的外置学生头像库。SAT 不是独立的游戏自动化程序，不启动模拟器、不执行咖啡厅任务，也不会替代 BACoffee 主程序。

## 一、运行前须知

1. 请从 BACoffee 官方 GitHub Release 下载完整发行包，并先将压缩包完整解压。
2. 请保持 `BACoffee SAT.exe`、`BACoffee.exe`、`runtime`、`assets` 和 `user_assets` 的相对目录结构不变。
3. SAT 使用发行包内 BACoffee 自带的便携 Python、OpenCV、NumPy 和 Pillow；用户不需要、也不应另行安装或配置 Python。
4. 不要单独复制 `BACoffee SAT.exe` 到桌面或其他目录运行。缺少 BACoffee 运行时会导致 SAT 无法启动。
5. 建议把整个 BACoffee 文件夹放在普通、可写的目录中，不要直接在压缩包内运行，也不要放在需要额外写入权限的系统目录中。

## 二、SAT 与 BACoffee 的关系

- SAT 只负责生成和写入外置学生头像。
- SAT 不修改 BACoffee 的内置学生头像。
- SAT 的默认写入位置是 `user_assets\students`。
- BACoffee 启动或重新打开学生选择界面时，会同时读取内置头像库和外置头像库。
- 如果外置头像与内置头像完整文件名相同（不区分大小写），BACoffee 以内置头像为准。
- 删除 SAT 不影响 BACoffee 已有的主要自动化功能，但会失去图形化头像导入工具。

## 三、使用方法

1. 关闭正在进行的 BACoffee 自动任务；如果 BACoffee 已打开学生选择窗口，请先关闭该窗口。
2. 双击 `BACoffee SAT.exe`。
3. 按界面提示确认 BACoffee 学生库位置。
4. 选择需要导入的 PNG、JPG、JPEG 或 WebP 图片。
5. 填写学生名称；如需区分服装或版本，在版本栏填写对应说明。
6. 检查自动裁剪结果，必要时调整裁剪位置和缩放比例。
7. 通过导入前检查后，点击导入。
8. SAT 会生成 BACoffee 可读取的 `92×92`、RGBA 四通道 PNG 文件。
9. 返回 BACoffee，重新打开学生选择窗口，即可查看新头像。

导入文件的完整文件名会作为学生标识和版本标识。请使用清晰、稳定且便于识别的名称，不要随意改变同一学生的命名规则。

## 四、文件安全和覆盖规则

- 单个导入结果不得超过 5 MB。
- SAT 不会覆盖内置学生头像。
- 遇到外置库同名文件时，SAT 会要求用户明确选择是否替换；默认操作是取消。
- 导入采用临时文件写入和完成后替换方式，以降低中途中断造成损坏的风险。
- 重要头像请自行保留原图备份。不要把 `user_assets\students` 当作唯一图片备份位置。
- 发布问题报告前，请检查截图、文件名和本地路径中是否含有不希望公开的信息。

## 五、隐私和网络

SAT 的图片读取、裁剪、格式转换和写入在本机完成。SAT 本身不需要上传头像，也不要求登录任何在线账号。操作系统、安全软件、GitHub 下载服务以及用户自行选择的存储或同步目录仍受各自隐私政策约束。

请勿导入、传播或公开发布无权使用的图片。用户应自行确认头像图片的著作权、肖像权、隐私权和其他使用授权。

## 七、常见问题

### 双击 SAT 没有启动

确认已经完整解压发行包，并且 `BACoffee SAT.exe` 与 `runtime` 文件夹仍位于同一发行目录。不要只复制一个 EXE。

### BACoffee 中没有出现新头像

关闭并重新打开 BACoffee 的学生选择窗口；确认图片位于 `user_assets\students` 第一层，并且文件为有效的 `92×92` RGBA PNG。

### 同名头像没有替换内置头像

这是预期行为。BACoffee 始终优先使用内置同名头像，外置头像不能静默覆盖内置资源。

### 安全软件提示未知程序

从项目官方 GitHub Release 下载，并核对 Release 页面提供的 SHA-256。不要通过关闭安全软件或添加全盘排除项来强行运行。若校验值不一致，请删除文件并重新下载。
