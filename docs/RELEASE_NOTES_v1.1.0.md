# BACoffee v1.1.0

改进咖啡厅邀请、任务调度和运行稳定性，新增可选的换装邀请与游戏更新下载功能。兼容 v1.0.1 的设置和用户导入头像。

## 更新内容

- 改进学生头像识别、邀请列表查找和换装邀请确认流程。
- 新增“允许邀请换装角色”选项，默认关闭。
- 新增“自动下载游戏更新”选项，默认关闭；开启前需要确认流量风险。
- 支持识别游戏维护提示并结束当前任务。
- 支持 1280×720、1600×900 和 1920×1080 三种 16:9 横屏分辨率。
- 改进 MuMu 启动与 ADB 连接。
- 手动执行与计划任务冲突时优先执行手动任务，避免重复运行。
- 改进任务取消和后续计划执行。
- 修复推迟任务后恢复默认计划时列表显示异常的问题。
- 改进唤醒计划状态显示。
- 精简运行日志，保留最近七天的日志，减少诊断文件占用。
- 减少发行包体积。
- 修复 BACoffee SAT 最大化时的布局问题。
- 优化学生列表和提示窗口的显示效果。

## 下载与升级

下载 `BACoffee_v1.1.0_Windows_x64.zip`，核对 `SHA256SUMS.txt` 后完整解压。GitHub 自动生成的 Source code 压缩包不能代替 Windows 发行包。

升级前退出正在运行的任务，将旧版的 `data` 和 `user_assets` 复制到完整解压的新版目录。请保留新版其余文件，不要只替换 EXE。更换安装目录后，请从新目录重新安装唤醒计划。

“允许邀请换装角色”可在“任务信息”中开启；“自动下载游戏更新”可在“设置”的“游戏更新”中开启。自动下载可能产生网络流量费用，请根据网络环境自行选择。

BACoffee SAT 需要与 BACoffee 主程序及随包资源保持在同一完整目录。首次使用时请在电脑旁观察完整流程。
