# BACoffee v1.0.1 版本说明

版本：`v1.0.1`  
平台：Windows x64  
发行日期：2026-09-22

## 本版定位

v1.0.1 是 BACoffee 与附属工具 BACoffee SAT 的首个公开正式版，提供咖啡厅辅助、学生邀请、摸头、定时执行、Windows 唤醒/休眠管理和学生头像导入等功能。

## 首次使用

1. 从 GitHub Release 下载 `BACoffee_v1.0.1_Windows_x64.zip`。
2. 核对 SHA-256 后，将压缩包完整解压到普通、可写的目录。
3. 双击 `BACoffee.exe`，完成渠道、MuMu 实例和咖啡厅设置。
4. 首次运行时请在电脑旁完成一次真实 MuMu 流程。

## 文件说明

- `BACoffee.exe`：主程序。
- `BACoffee SAT.exe`：学生头像导入辅助工具。
- `BACoffee.py`：计划任务和便携运行时所需的旁置源码，请保留。
- `runtime`：便携 Python 及共享依赖，请保留。
- `data`：本机设置与运行日志，初始发行包不含真实用户数据。
- `user_assets\students`：用户外置头像目录，初始发行包仅含说明文件。

完整发行说明见 `RELEASE_NOTES.md`，使用前请阅读 `README.md` 与 `DISCLAIMER.md`。
