# BACoffee v1.1.0 版本说明

平台：Windows x64。

兼容 v1.0.1 的设置与用户导入头像，更新内容见发行说明。

## 发行目录

- `BACoffee.exe`：主程序。
- `BACoffee SAT.exe`：学生头像导入工具。
- `BACoffee.py`、`sat_source`、构建元数据、`runtime`、`third_party` 和 `assets`：运行所需文件，请保留。
- `data`：设置、日志和任务记录。
- `user_assets/students`：用户导入的学生头像。

请下载并完整解压 `BACoffee_v1.1.0_Windows_x64.zip`，不要只复制 EXE。升级和使用方法见 README。
