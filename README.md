# BACoffee

BACoffee 是部分基于 BAAS、BASH 相关代码与工作流程进行二次开发，并在此基础上完成改进、功能升级、流程整合和 UI 美化的非官方《蔚蓝档案》咖啡厅辅助工具。它面向 Windows 与 MuMu 模拟器环境，提供咖啡厅流程、学生邀请、摸头、定时执行、Windows 唤醒/休眠管理，以及附属学生头像导入工具 BACoffee SAT。

> 当前版本：`v1.1.0`。更新内容见 [CHANGELOG.md](CHANGELOG.md)。

## BACoffee SAT

`BACoffee SAT.exe` 是 BACoffee 的附属学生头像导入工具。它负责完成用户图片的检查、裁剪，并写入 `user_assets\students`，BACoffee 随后读取这些外置头像。

SAT 需要完整发行包才能运行。详细说明见 [SAT 使用前请阅读](docs/SAT_使用前请阅读.md)。

## 首次使用

1. 完整解压 Release 包。
2. 双击 `BACoffee.exe`。
3. 选择官服或 B服、MuMu 实例和咖啡厅设置。
4. 首次运行时在电脑旁观察完整流程。
5. 确认普通运行正常后，再决定是否安装 Windows 唤醒计划。

请保留发行目录中的程序、脚本和资源文件，以免影响运行与计划任务。

注意唤醒计划仅能唤醒休眠状态电脑，关机状态无效。

## 本地数据

程序会在 `data` 中保存设置、日志、结果和诊断信息，并在 `user_assets\students` 中保存用户导入的头像。上述内容可能含有本地路径、设备状态或用户图片，不应直接上传到公开 Issue。

## 从 v1.0.1 升级

请先退出正在执行的任务，保留旧版的 `data` 和 `user_assets`，再将这两个目录迁移到完整解压的新版目录。不要混用新旧 EXE、源码或元数据。更换安装目录后，从新目录重新安装唤醒计划。

新增“允许邀请换装角色”选项，默认关闭，可在“任务信息”中开启。升级后原有设置和学生选择继续保留。首次使用换装邀请时请观察游戏内确认流程。

新增“自动下载游戏更新”选项，默认关闭，可在“设置”的“游戏更新”中开启；开启前请确认网络流量风险。关闭时遇到更新下载提示会结束当前任务，后续计划保留。

安装唤醒计划后，请在 Windows 任务计划程序中确认任务已启用，并检查电脑是否允许定时唤醒。

源码构建方法见 [构建说明](docs/BUILD_GUIDE.md)。

## 支持的分辨率

支持 1280×720、1600×900 和 1920×1080 三种 16:9 横屏分辨率，建议使用 1920×1080。不支持竖屏、超宽屏及其他非 16:9 布局。
