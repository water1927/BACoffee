# Security policy

Please do not include passwords, tokens, cookies, webhooks, account identifiers, device identifiers, local paths or unredacted `data/` files in an issue.

For a suspected security problem, first stop unattended execution and preserve only the minimum redacted evidence needed to reproduce it. Public reports should describe the affected release, operating-system version, MuMu/Android combination and a safe reproduction summary without private data.

The project does not promise security support for modified, repacked or partially extracted releases.
